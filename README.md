# 配車さん（haisha-san）

複数人で同じ目的地へ車で向かうときに、メンバーの出発地・車の定員・目的地から、車ごとの乗車メンバーと集合地点を提案する配車プランナーです。

旅行、キャンプ、イベントなどで発生する「誰がどの車に乗るか」「どこに集まるか」「席が足りるか」の調整を支援します。

## 主な機能

- 目的地、メンバー名、出発地、運転可否、車の定員を入力
- 一緒の車に乗りたいメンバーを同乗グループとして固定
- ドライバーごとに任意の集合場所を指定（自宅を集合場所にすることも可能）
- メンバー住所録のCSV読み込み・書き出し
- 車なしメンバーを、定員を守りながら地理的に近いドライバーへ割り当て
- 車ごとに駅・駐車場などの集合地点を提案
- 次の3つから最適化方針を選択
  - バランス
  - 集合のしやすさ重視
  - ドライバー負担重視
- 車ごとの乗車メンバー、集合地点、概算時間、遠回り時間を表示
- 席不足や車がない場合は、公共交通で向かうメンバーとして案内
- Google Mapsのルートリンクと、コピーしやすい共有テキストを生成
- DBを使わない閲覧専用の共有URLを発行

## 動作モード

### サンプルモード

`GOOGLE_MAPS_API_KEY` を設定せずに起動するとサンプルモードになります。内蔵の住所辞書、主要駅リスト、直線距離ベースの概算を使うため、Google Maps Platformの設定なしでUIと割り当てロジックを試せます。

トップ画面の「サンプルデータを読み込む」から、すぐに計算を実行できます。内蔵辞書にない住所は解決できません。

### ライブモード

`GOOGLE_MAPS_API_KEY` を設定すると、住所解決、集合地点検索、車の移動時間、公共交通経路の取得にGoogle Maps Platformを利用します。外部APIの取得に失敗した箇所は、可能な範囲で内蔵データや概算値へフォールバックします。

## セットアップ

### 必要なもの

- Node.js 20以降
- npm
- Google Maps PlatformのAPIキー（ライブモードを使う場合のみ）

### 起動手順

```bash
git clone <repository-url>
cd haisha-san
npm ci
cp .env.example .env.local
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。サンプルモードだけを使う場合、`.env.local` のAPIキーは空のままで構いません。

本番相当で起動する場合は次のコマンドを使います。

```bash
npm run build
npm start
```

## Google Maps Platformの設定

`.env.local` にキーを設定します。

```dotenv
# Route Handlerからのみ参照するサーバー用キー
GOOGLE_MAPS_API_KEY=

# 住所サジェストを使う場合だけ設定するブラウザ用キー
NEXT_PUBLIC_GOOGLE_MAPS_BROWSER_KEY=
```

サーバー用キーでは、次のAPIを有効にしてください。

- Geocoding API
- Places API
- Routes API

ブラウザ用キーは任意です。設定すると入力欄で日本国内の住所候補が表示されます。Maps JavaScript APIとPlaces APIを有効にし、HTTPリファラー制限とAPI制限を設定してください。サーバー用キーとブラウザ用キーは分けて運用することを推奨します。

Google Maps Platformの利用には、Google Cloudプロジェクトでの請求先設定が必要になる場合があります。料金・割り当て・利用条件はGoogleの最新情報を確認してください。

## 使い方

1. 目的地を入力します。
2. メンバーを追加し、名前と出発地を入力します。
3. 車を出せるメンバーは「車あり」を選び、ドライバー本人を含む定員を入力します。
4. 最適化の方針を選び、「計算する」を押します。
5. 車ごとの乗車メンバー、集合地点、移動時間、Google Mapsリンクを確認します。
6. 必要に応じて共有テキストをコピーするか、幹事メモを添えて共有URLを発行します。

結果はブラウザのメモリだけに保持されるため、結果画面をリロードすると消去されます。

## CSV住所録

「CSVに書き出す」で、現在のメンバー一覧を端末へ保存できます。目的地と緯度経度は含まれません。

読み込み時は、少なくとも氏名と住所の列が必要です。

```csv
氏名,住所,運転,定員,同乗グループ,指定集合場所
田中,東京都新宿区,はい,4,1,新宿駅
鈴木,東京都中野区,いいえ,,1,
```

`同乗グループ` と `指定集合場所` は任意です。同じグループのメンバーは同じ車へ割り当てられます。英語の列名（`name`, `address`, `driver`, `capacity`, `group`, `meetingPoint`）にも対応しています。

## プライバシー

- 入力した氏名、住所、目的地はLocalStorage、SessionStorage、IndexedDB、DBへ保存しません。
- ライブモードでは、住所や座標をアプリのRoute Handler経由でGoogle Maps Platformへ送信します。
- CSVを書き出した場合、氏名と住所を含むファイルが利用者の端末に保存されます。
- 共有URLには、目的地の表示名、氏名、配車結果、集合地点、Google Mapsリンク、幹事メモが含まれます。
- 共有URLに、メンバーの出発地住所、自宅の緯度経度、住所解決の詳細、公共交通の詳細経路は含めません。
- 共有データは圧縮してURLの `#` 以降に格納し、サーバーへ保存しません。
- 共有URLを知っている人は閲覧できます。有効期限、削除、アクセス制限はありません。

## 構成

```text
app/
  page.tsx              # 入力画面
  result/page.tsx       # 計算結果と共有URLの発行
  s/page.tsx            # 共有URLの閲覧専用画面
  api/                  # Google Maps PlatformへのRoute Handler
components/             # 住所サジェストなどのUI
lib/
  planner/              # 入力検証、割り当て、集合地点選択、最適化
  google-maps/          # APIクライアントとGoogle Mapsリンク生成
  share-url/            # 共有データの最小化、圧縮、復元
  io/                   # CSV住所録の読み書き
docs/                    # 要件定義と実装ガイド
```

割り当ては実用的な近似アルゴリズムです。厳密な最適解を保証するものではないため、実際の道路状況、停車可否、各メンバーの事情を確認したうえで利用してください。

詳細は [要件定義](docs/carpool-meeting-planner-requirements.md) と [実装ガイド](docs/carpool-meeting-planner-implementation-guide.md) を参照してください。
